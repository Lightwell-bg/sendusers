Доступ с внешних адресов

Статус: {% if external_access %} Включён {% else %} Выключен (только через SSH-туннель) {% endif %}

По умолчанию панель отвечает только на запросы с локальных/туннельных адресов — прямые обращения с внешних IP получают отказ ещё до формы входа. Если включить, порт станет доступен всем: трафик идёт по HTTP без шифрования — пароль и сессионная cookie передаются открытым текстом, и порт будут сканировать боты. Включайте, только если временно нужен доступ без туннеля, и выключайте обратно сразу после.

Параметры рассылки

Применяются сразу, без рестарта контейнера — ближайшая отправка/dry-run подхватит новое значение.

Ограничение Telegram — около 12 сообщений в секунду, значит не меньше ~0.08.

Можно кэшировать надолго — устаревание тут стоит недорого: лишний пропуск, не более.

Короче предыдущего: устаревание тут значит письмо тому, кто уже вступил в чат.

Участников этих чатов/каналов не рассылаем.

Сюда уходит «тестовая отправка на себя»; узнать свой ID можно у @userinfobot.
